# GoAyvalık — Search / AI Discovery Visibility Map

## Entity role
Utility/product-led Ayvalık discovery platform: maps, structured place data, hotels, events, guides and app/web user flows. Keep this distinct from Ayvalık Vibes' editorial/media role to reduce cannibalization.

## Priority query clusters
- Ayvalık gezi rehberi
- Ayvalık harita
- Ayvalık nerede ne yapılır
- Ayvalık oteller
- Cunda oteller
- Ayvalık etkinlik takvimi
- Ayvalık mekan rehberi
- Ayvalık restoran / kafe / plaj discovery
- Ayvalık 365 gün
- Ayvalık uygulaması / şehir rehberi

## Search strategy
- Stable canonical entity/place pages with accurate name, category, coordinates/address, contact, official site/social links and freshness metadata.
- Separate structured utility pages from editorial stories; cross-link to Ayvalık Vibes where editorial depth is stronger instead of duplicating text.
- Use LocalBusiness/Event/Breadcrumb/Organization structured data only for verified data represented on the page.
- Maps/place listings must not invent ratings, opening hours, websites or contact information.
- Build useful category/area hubs from real inventory and data, not empty doorway pages.
- Maintain bilingual/hreflang integrity where English is offered.

## AI/agent readiness
Machine-readable place data, stable URLs, semantic HTML/accessibility tree, clear actions and current facts help browser/search agents use the product. Keep high-value public guide/place content crawlable while protecting member/admin/private surfaces.
