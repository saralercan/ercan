# SWE-bench prediction inputs

This directory is reserved for explicitly reviewed SWE-bench prediction JSONL files used by the manual cloud-evaluation workflow.

Rules:
- prediction files are generated by an actual recorded model/agent runtime;
- no customer, production, secret or private project data;
- format must contain `instance_id`, `model_name_or_path`, and `model_patch` per line;
- validate with `python3 scripts/validate_swebench_predictions.py <file>` before dispatch;
- changed predictions require a new unique SWE-bench `run_id`;
- gold/reference patches are harness validation only and must never be reported as Ercan OS agent performance;
- large/transient prediction sets should normally be kept as benchmark artifacts rather than accumulated indefinitely in git.
