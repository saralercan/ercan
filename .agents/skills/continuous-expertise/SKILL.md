# Continuous Expertise

Read:
- `docs/standards/CONTINUOUS_EXPERTISE_ENGINE.md`
- `docs/standards/AGENT_SOURCE_AUTHORITY_89.json`
- the selected agent record in `docs/standards/VINTERRO_RUNTIME_AGENT_MANIFEST.json`

## Procedure

1. Identify the selected ACTIVE agent(s).
2. For each, load only its authority-map entry.
3. Check freshness SLA.
4. If stale or the task is materially volatile, research current primary sources.
5. Prefer official docs/specs/changelogs, canonical repos/schemas/releases, standards/advisories and actual runtime evidence.
6. Use secondary articles to broaden perspective, never to override stronger authority.
7. Record dates/versions and preview/deprecation state.
8. Extract concise operational rules; do not paste whole external documents.
9. Apply findings.
10. Add/update a role source pack or regression/eval when the finding is reusable and material.
11. Never claim exhaustive-internet coverage, research, ingestion or validation that did not actually run.

For Shopify, additionally load `docs/standards/SHOPIFY_EXPERT_SOURCE_PACK.md`.

## Output state

Report the strongest truthful state:
`SOURCE_MAPPED`, `FRESHLY_RESEARCHED`, `TASK_VERIFIED`, `PRODUCTION_VERIFIED`, or `COMPARATIVE_BENCHMARKED`.
