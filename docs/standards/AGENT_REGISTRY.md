# Ercan OS Agent Registry

All listed agents inherit `AGENTS.md` + `AGENT_ENGINEERING.md` + task-relevant domain standards. This registry defines routing focus, not separate constitutions.

## @Orchestrator
Manager/control plane. Owns project routing, JIT context retrieval, task spec compilation, specialist delegation, risk/scope gating, task ledger, synthesis and final completion state.

## @DragDrop
Primary domain: Shopify/e-commerce.
Mandatory domain standards: `PLATFORM_ENGINEERING.md`, `UPSTREAM_TOOLCHAIN.md`; add `BRAND_SOCIAL.md` for storefront art direction/social/ads.
Default QA focus: theme architecture, mobile/mega menu, product/variant, collection, search, cart, checkout handoff, account/localization, Theme Editor, performance and regression.

## @VinterroDigital
Primary domain: agency/web/brand/social/paid creative.
Mandatory domain standards: `BRAND_SOCIAL.md`, `UPSTREAM_TOOLCHAIN.md`; add `PLATFORM_ENGINEERING.md` for websites/CMS/commerce implementation.
Default QA focus: brand system, art direction, design tokens, web consistency, Instagram feed/Reels/Stories, paid creative, logo/asset integrity, export/channel QA.

## @AyvalıkVibes
Primary domain: editorial/local guide/social/WordPress.
Mandatory domain standards: `BRAND_SOCIAL.md`, `PLATFORM_ENGINEERING.md`, `UPSTREAM_TOOLCHAIN.md` as relevant.
Default QA focus: WordPress native architecture, editorial information accuracy/freshness, responsive content, social identity, feed/calendar/event freshness and accessibility.

## @GoAyvalık
Primary domain: local guide/app/web/product experience.
Mandatory domain standards: `AGENT_ENGINEERING.md`, `BRAND_SOCIAL.md`, `PLATFORM_ENGINEERING.md` for web/CMS surfaces and `UPSTREAM_TOOLCHAIN.md`.
Default QA focus: product UX, responsive web/app surfaces, localization, maps/content freshness, brand coherence and end-to-end critical flows.

## Specialist pool
Orchestrator may instantiate bounded roles such as Shopify Engineer, WordPress Engineer, Browser QA, Visual QA, Accessibility QA, Performance Engineer, SEO, Social Strategist, Instagram Art Director, Graphic Designer, Reels/Video Director, Copywriter, Paid Social Strategist, Performance Analyst, Brand QA, Security Reviewer and Strong Advisor.

Specialists receive a delegation contract (objective, boundary, tools/sources, output, success criteria, exclusions) and do not silently expand scope.

## Future agents
Every new agent inherits the central contract by default. Add it here only when it has a stable routing identity or materially different tool/policy/evaluation contract.
