## Research hierarchy

Prefer:
1. official platform/standards docs;
2. maintained canonical open-source tools/skills;
3. respected research/practice sources;
4. community patterns;
5. generic model memory last.

## Key authority map

### UI/UX
- W3C/USWDS/GOV.UK for accessibility/research-backed interaction patterns;
- NN/g for usability/research heuristics;
- reviewed open-source UI skills for implementation patterns.

### SEO/AEO
- Google Search Central/Search Essentials as primary search authority;
- Search Console evidence;
- maintained measurement-first SEO skills as implementation aids;
- agentic/AEO tools only as directional heuristics.

### Meta
- current Meta for Business/Ads Manager documentation;
- authenticated account evidence for actual campaign state;
- first-party Pixel/CAPI event evidence for measurement.

### Analytics
- current GA4/GTM developer docs;
- observed event payloads and DebugView/realtime evidence.

### Security
- OWASP Top 10:2025 for risk awareness;
- OWASP ASVS 5.0 for verification requirements;
- MDN/current platform docs for browser controls;
- deterministic scans + manual threat/access/session review.

## Cross-specialist rule

No specialist may silently redefine another domain:
- UI cannot override accessibility;
- CRO cannot override truthful content or privacy;
- SEO cannot damage UX/accessibility merely for crawler heuristics;
- Meta cannot bypass consent;
- analytics cannot collect data outside consent/policy;
- security cannot be marked verified by a single scanner;
- graphic design cannot violate brand/source rights.

## Evidence

Claims should distinguish:
- measured;
- observed;
- inferred;
- recommended;
- unverified.
