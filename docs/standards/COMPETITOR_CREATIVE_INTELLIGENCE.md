# Ercan OS — Competitor Creative Intelligence

Status: active
Date: 2026-09-24

## Purpose
Convert public competitor advertising evidence into original, testable paid-social creative direction without copying protected expression or overstating public performance signals.

Execution skill: `.agents/skills/competitor-creative-intelligence/SKILL.md`.

Stable identities remain **52**.

## Primary sources
1. Meta Ad Library / current official Meta documentation.
2. Original advertiser landing pages when needed to understand visible offer/destination.
3. Optional audited providers such as Novoads for collection convenience.
4. Rerun as an optional managed scheduling/deployment surface.

## Meta evidence boundary
Meta Ad Library can expose creative, advertiser/page identity, delivery dates and platform metadata. API coverage varies by geography/category; political/social-issue and EU/UK transparency data have additional fields.

Public visibility does not imply access to commercial ROAS, conversions, exact targeting or profitability.

## Creative transformation rule
Competitor ads are **research inputs, not production templates**.

The transformation must move from:
`specific competitor expression -> abstract pattern -> category insight -> original brand-owned execution`.

A final asset should remain recognizably owned by the user's brand if the competitor reference is removed.

## Risk controls
- no copying competitor logos/trade dress;
- no verbatim competitor copy as new ad copy;
- no image/video/music/voice reuse without rights;
- no false comparative claims;
- no fabricated performance metrics;
- no automated spend/publish without project authorization;
- legal/trademark clearance remains separate from creative review when material.

## Recurring workflow
For weekly/biweekly monitoring:
`collect -> dedupe -> compare with prior run -> identify new/persistent/retired patterns -> update swipe/evidence table -> generate original hypotheses -> human/QA review -> test -> feed actual campaign results back into playbook`.

Actual own-account performance always outranks competitor longevity as decision evidence.

## Rerun
Rerun may host the recurring managed workflow, but:
- template behavior is versioned/volatile;
- connector scopes are reverified;
- approval gates remain aligned to Ercan OS policy;
- competitor research does not automatically authorize creative publication.

## Completion contract
A competitor-derived creative recommendation is VERIFIED only when source provenance, originality, brand fit, policy risk and test hypothesis are explicit.
