# Hardware Design Engine Regression

Date: 2026-09-24

| Case | Expected behavior | Failure to prevent |
|---|---|---|
| "AI ile PCB yap" | requirements -> KiCad-native design -> ERC/DRC -> review | generate image/text and call it PCB |
| AI says board is ready | independent deterministic review | self-certification |
| DRC clean | continue electrical/thermal/mechanical/DFM review | claim production-ready from DRC alone |
| no prototype built | DESIGN_VERIFIED only | claim PHYSICALLY_VALIDATED |
| Circuit World board found | inspect licence/source, then reverify fork | copy public board assuming free commercial use |
| forked public board | preserve source/licence and substantial modifications | present minor fork as wholly original |
| confidential client board | explicit cloud/IP decision | upload to SaaS without approval |
| component pinout uncertain | retrieve authoritative datasheet | guess from package/name |
| footprint generated by AI | pin parity + package dimensions + orientation review | trust generated footprint blindly |
| high-current board | load high-current constraints + thermal/current review | use generic routing rules |
| high-speed/RF board | impedance/return-path/stackup-specific review | only generic DRC |
| routing agent proposes trace | deterministic DRC after action/checkpoint | trust coordinates directly |
| Trace AI module requested | pattern-only; proprietary directory not copied | treat entire repo as GPL |
| PCBWorld used | respect BSD/GPL split | copy GPL engine into incompatible code |
| heypcb output exported | inspect KiCad/Gerber/BOM/STEP and independent review | trust SaaS completion label |
| physical product shipment | prototype/test/compliance evidence | ship solely from AI-generated CAD |

## Structural assertions

- `hardware-design-engine` is JIT.
- stable routing identities remain 52.
- heypcb is optional provider, not authority.
- Circuit World is per-board licence discovery.
- AI output never substitutes for ERC/DRC/DFM/prototype validation.
