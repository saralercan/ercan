## Structural assertions
- `judgment-engine` is JIT, not a new stable identity.
- official TypeSafe sources outrank community demos for API behavior.
- Canny patterns extend, not replace, Ercan OS completion governance.
- desktop automation stays permission-scoped.
- financial and physical-control examples are not promoted to autonomous production authority.
