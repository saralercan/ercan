# Vinterro Creative Presentation Style — Regression Gate (2026-10-26)

Use with `docs/standards/VINTERRO_PRESENTATION_CREATIVE_STYLE.md` for all future `@Presentation` work.

## Automatic review checklist (PASS/FAIL/NOT-TESTED)

1. **Routing:** the Presentation Agent loaded the operator-approved creative default and matching project/customer brand.
2. **Visual language:** ink/paper base; approved palette; disciplined accent usage; editorial hierarchy; differentiated content-driven layouts; no generic AI card grid.
3. **Source integrity:** all required statements, numbers, evidence, severity, limitations and user corrections survive transformation unchanged.
4. **Presentation craft:** readable type, safe margins, sufficient breathing room, no overflow/cropping; charts properly sourced; actual imagery.
5. **Format integrity:** editable PPTX/Slides when requested; native objects where practical; no silent full-slide flattening.
6. **Interaction fidelity:** HTML links/filters behave; PDF/PPTX do not imply nonworking clickable UI affordances.
7. **Accessibility/print:** reading order, visible links, contrast, keyboard focus in HTML, PDF page breaks and color preservation.
8. **Independent QA:** render every slide/page, inspect exports against source, rerender changes, do not self-certify.
9. **Default vs override:** if client/user supplies a mandatory brand/template, adapt without overwriting their identity.
10. **Release honesty:** claims of VERIFIED only when validation evidence exists; otherwise PARTIAL or NOT_VERIFIED.

## Failure fixtures

- Generic white deck with centered title + repeated colored boxes, despite no client override: FAIL.
- Aesthetic PDF with cropped issue text or missing test statuses: FAIL.
- "Green" test shown without label or evidence: FAIL.
- "Editable PowerPoint" made of flattened page screenshots: FAIL.
- A branded client template requested yet replaced by Vinterro palette: FAIL.
- Accurate, evidence-linked editorial deck using approved tokens, readable variety and independently reviewed editable output: PASS.

This is a QA contract, not evidence that any running agent actually performed its review.
