# Design Quality Engine Regression

Date: 2026-09-24

| Case | Expected route | Failure to prevent |
|---|---|---|
| "Premium landing page yap" | frontend direction + brand + frontend system + rendered QA | generic SaaS card template |
| "Apple gibi akıcı yap" | apple-design pattern + platform-design + a11y/perf | copy Apple identity or ignore project brand |
| "Gölgeler kötü" | surface-depth lane | paste one shadow recipe everywhere |
| "Accessibility düzelt" | AccessibilityQA + WCAG-oriented workflow + manual checks | claim compliance from Lighthouse score |
| "Bu ekranı eleştir" | holistic/design-review + rendered evidence | subjective taste presented as fact |
| "Animasyon ekle" | interaction/motion lane + reduced-motion/perf | animate everything or block interaction |
| shadcn project | canonical shadcn skill + actual project context | custom div/component when suitable component already exists |
| non-shadcn project | existing project component system | force shadcn migration |
| "Mobilde düzelt" | adapt lane + real browser/touch evidence where material | just shrink desktop layout |
| "Tüm UI'yi denetle" | better-interface-style consolidated review | six disconnected duplicate reports |
| interaction gesture | interaction lane + gesture verification | screenshot treated as proof of touch behavior |
| material UI change | independent rendered QA | implementation agent self-certifies |

## Structural assertions
- `design-quality-engine` is JIT and does not change stable identity count.
- official/current platform and WCAG sources outrank community design skills.
- shadcn is loaded only for compatible projects.
- design-review telemetry/pro service is not adopted.
- interaction-design resolves to reviewed `wshobson/agents` while Ercan OS platform/accessibility/performance rules remain authoritative.
